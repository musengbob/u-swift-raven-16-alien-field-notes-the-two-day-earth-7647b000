## The entry

`main.ts` writes one original line — an alien tourist's review of planet Earth — to `/output/entry.txt`:

> Two days on Earth: the locals feed a small furry creature on schedule, let it sleep on their bed, and apologise when it ignores them. Clearly not the species in charge here. 4/5 stars.

184 characters, one line, one clean joke: the alien watches humans serve their pets and concludes the pets run the planet.

## Run

```sh
node main.ts
```

Writes `/output/entry.txt` (override the directory with `OUTPUT_DIR`).
